# پلن ۰ — تعیین و تثبیت مرز شیفت/فلوکارت

**وابسته به**: هیچ‌چیز. **چرا اول**: بدون این قرارداد، هر پلن بعدی دوباره دو محصول را در هم می‌بافد.

- تعریف لایه پلتفرم مشترک و جابه‌جایی منطق مشترک به آن (داده، ایجنت، محاسبه، هویت).
- افزودن مفهوم `surface` و پرچم‌های مرچنت به‌عنوان تنها راه تفاوت رفتار.
- قاعده «بدون import متقابل» + تست ساختاری که این قاعده را چک کند.
- پایان: نقشه پوشه‌ها و قرارداد تایپ‌ها مشخص است و یک تست شکست می‌خورد اگر مرز نقض شود.
