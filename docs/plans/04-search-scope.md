# پلن ۴ — دامنه جست‌وجو (یک موتور، دو دامنه)

**وابسته به**: پلن ۳. **چرا این‌جا**: تا دامنه در جست‌وجو اعمال نشود، نشتی کاتالوگ بین مرچنت‌ها ممکن است.

- گسترش `pet_hybrid_search` و `hybrid_product_search` با پارامتر دامنه: `p_merchant_id` برای شیفت، فیلتر «واجد شرایط فلوکارت» برای فلوکارت.
- سازگاری امضای فعلی، تا پت‌آباد و فلوکارت امروز نشکنند.
- تست نشتی: جست‌وجوی مرچنت الف هرگز کالای مرچنت ب را برنگرداند.
- پایان: یک لایه دسترسی، نه دو کاتالوگ.
