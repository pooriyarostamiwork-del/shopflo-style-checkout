# پلن ۵ — پلاگین ووکامرس: اسکلت، امنیت و پنل وردپرس

**وابسته به**: پلن ۳ (کلید مرچنت لازم است). **چرا این‌جا**: دروازه ورود همه داده واقعی است.

- پلاگین PHP مشترک `flow-connector` (WordPress ≥ ۶، WooCommerce ≥ ۷)، یک کلید اتصال و یک شناسه فروشگاه.
- امضای HMAC روی بدنه + timestamp + nonce در هر دو جهت، پنجره ۵ دقیقه، رد nonce تکراری.
- مسیرهای REST زیر `/wp-json/flow/v1/`: `ping`, `config`, `identity/resolve`, `cart/quote`, `order/create`, `order/status`, `order/track`.
- صف retry با backoff و لاگ، تا هیچ داده‌ای در قطعی گم نشود.
- پنل وردپرس حداقلی: بلوک اتصال (کلید، شناسه، وضعیت، آخرین ارتباط)، بلوک محصولات (کلید روشن/خاموش فلوکارت و شیفت + دکمه ورود به داشبورد)، بلوک نسخه و به‌روزرسانی امضاشده. هیچ تنظیم عملیاتی در وردپرس نیست.
- پایان: نصب پلاگین روی یک سایت آزمایشی و پاسخ موفق `ping`.
