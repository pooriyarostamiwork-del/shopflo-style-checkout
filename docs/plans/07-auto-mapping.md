# پلن ۷ — موتور نگاشت خودکار

**وابسته به**: پلن ۶، پلن ۲.

- ترتیب تطبیق: بارکد/شناسه یکتا ← برند + خط محصول + وزن/حجم + گونه ← تطبیق معنایی با امبدینگ و متن، با آستانه اطمینان.
- امتیاز اطمینان برای هر نگاشت؛ زیر آستانه بالا «نیاز به تأیید انسانی»، نه رد.
- دلایل ثبت‌شده نگاشت‌نشدن: نبود معادل، چند کاندید نزدیک، داده ناقص، دسته خارج از حوزه، تناقض گونه/نوع، تصویر خراب، تکراری در همان مرچنت.
- اجرای غنی‌سازی و امبدینگ فقط برای ردیف‌های واقعاً تغییرکرده.
- پایان: صف نگاشت با دلیل پر می‌شود و هیچ مورد مبهمی خودکار نگاشت نمی‌شود.
