# پلن ۲۶ — ورود وندور و نقش‌ها

**وابسته به**: پلن ۳. **موازی با بیشتر پلن‌ها.**

- ورود با شماره موبایل و کد یک‌بارمصرف روی همان زیرساخت OTP فعلی؛ هیچ یوزرنیم/پسورد دستی.
- ساخت مرچنت در پنل داخلی با شماره مالک؛ همان شماره اجازه ورود دارد.
- جدول نقش‌های جدا (مالک مرچنت، اپراتور مرچنت، اپراتور داخلی) + دسترسی سطح-ردیف؛ دعوت اعضا با شماره موبایل.
- کلید اتصال پلاگین قابل دیدن و بازتولید؛ پنل QC فقط برای اپراتور داخلی.
- پایان: وندور فقط داده خودش را می‌بیند.
